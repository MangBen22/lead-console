# Phase 271: CRM SMTP Filters

## Summary
- Turned CRM SMTP status into a filtered and paginated site inventory.

## API
- `crm.smtp.summary`
  - Supports:
    - `site_id`
    - `connection`
    - `confirmation`
    - `search`
    - `page`
    - `limit`

## UI
- Added CRM SMTP filters for site, connection state, confirmation state, search, page, and limit.
