# External Dependencies Checklist

## Access Needed Before Full Build
1. Hostinger server access for deployment pipeline.
2. Subdomain and SSL for `app.5n2digital.com`.
3. API credentials for selected CRM providers.
4. API credentials and app review status for social platforms.
5. SMTP provider account for production testing.

## Legal and Compliance Inputs
1. Approved platform list for connectors.
2. Data retention policy and deletion windows.
3. Terms acceptance flow for client accounts.
4. Audit log retention period.

## Product Defaults (Current)
1. Internal single-tenant operation.
2. Notifications through web and email.
3. AI disabled for paid API control (hybrid rules/FAQ support only).
