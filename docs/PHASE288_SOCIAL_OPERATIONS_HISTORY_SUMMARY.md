# Phase 288: Social Operations History Summary

## Summary
- Added aggregated Social operations history summaries with averages and first-vs-latest deltas.

## API
- `social.operations.history_summary`
  - Input:
    - `limit`
  - Returns:
    - run count
    - latest and oldest history entries
    - averages for key Social operations metrics
    - changes between latest and oldest runs

## UI
- Added a Social operations history summary view under the Social operations section.
