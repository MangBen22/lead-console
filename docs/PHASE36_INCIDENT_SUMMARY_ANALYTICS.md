# Phase 36 Incident Summary Analytics

## Delivered
- Added endpoint:
  - `deployment.incident.summary`
- Added Deployment Guard UI panel:
  - `Refresh Incident Summary` button
  - incident summary viewer

## Summary Metrics
- incident counts by status (`open`, `resolved`, `reopened`, `unknown`)
- total incident reports
- open incident total (`open + reopened`)
- resolution metrics:
  - sample count
  - average resolution minutes
  - max resolution minutes
- latest open/reopened incident items

## Purpose
Provides fast operational visibility into incident backlog and closure performance.
